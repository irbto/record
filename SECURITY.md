# Security policy

## Supported versions

We apply security fixes to the latest release and `main`.

## Reporting a vulnerability

Use GitHub private vulnerability reporting. Do not open a public issue for a vulnerability that can put users or recordings at risk.

Give the affected version, Windows version, steps to reproduce the problem, and possible effect. We will acknowledge the report within seven days.

`record` writes only to the selected output path. It does not replace files by default.

If capture or encoding fails, `record` removes the incomplete file.

Before you record audio, learn the applicable laws and consent rules. You are responsible for compliance.
