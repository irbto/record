# Security policy

## Supported versions

Security fixes are applied to the latest release and `main`.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue for a vulnerability that could put users or their recordings at risk.

Include the affected version, Windows version, reproduction steps, and expected impact. You should receive an acknowledgement within seven days.

`record` writes only to the requested output path, refuses to replace files by default, and removes incomplete outputs when native capture or encoding fails. Treat recording laws and consent requirements in your jurisdiction as the user's responsibility.
